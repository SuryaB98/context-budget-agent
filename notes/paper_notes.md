## 2. Deep Notes on Foundational Papers (Ready for Interim Report Section 3.2)

### 2.1 Tool-Schema Compression (`arXiv:2605.26165`)
- **Core Premise:** Modern MCP and API tool servers expose dozens of tools whose JSON schemas consume thousands of tokens before the first user turn.
- **Verified Finding:** Across 14 local models (`1.5B`–`32B`) + a frontier API over `6,566` controlled calls and `28` tools, raw JSON schemas collapse to **`2.6%` average exact-match (EM)** at an `8k` window. Conservative schema compression (TSCG) cuts schema tokens by `44%–50%`, lifting EM by **`+20.5 pp`** on average (`+24.7 pp` across the six fully enabled models), whereas at `32k` the effect vanishes ($\Delta \le 1\text{ pp}$).
- **Distinction from Our Work:** `2605.26165` trades off **Schemas ($S$) vs. Static RAG Evidence ($E$)**. In transactional customer-service agents (`tau2-bench@v1.0.1` Retail), facts arrive dynamically inside **Interaction History ($H$)** from sequential tool calls (`find_user_id_by_email`, `get_order_details`, `get_product_details`), governed by a strict **Operational Policy ($P$)**.

### 2.2 Control Under Compression (`arXiv:2608.01056`) & Governance Decay (`arXiv:2606.22528`)
- **Core Premise:** Compressing persistent agent control instructions or compacting multi-turn history introduces sudden reliability cliffs and silent policy failures.
- **Verified Findings:** Hou & Yang (`2608.01056`, `CompressAgent`, `15,525` runs) identify three zones: near-full reliability at `75%` retention (`92.4–92.7%` vs. `93.8%` full), a sharp transition between `50%` and `35%` (dropping to `19.9%–47.0%`), and total protocol breakdown below `25%`. `2606.22528` (`ConstraintRot`, `1,323` episodes) shows context compaction drives safety/policy violations from **`0%` to `30%`** (up to `59%`), with soft organizational rules decaying **`8.3×`** faster than hard norms, while **Constraint Pinning** (`~47` tokens) restores `0%`.
- **Distinction from Our Work:** Standard benchmarks like `tau2-bench` grade terminal database state and miss intermediate procedural breaches (e.g., cancelling an order without authenticating the user or obtaining explicit confirmation). Our 8-rule deterministic compliance engine (`src/compliance_checkers.py`) isolates **Silent Policy Violations** across controlled `S:H` ratios and tests pinned vs. BM25-retrieved policy (`RQ1b`).

### 2.3 Post-Training vs. Context Engineering (`PA-Tool`, `ToolRL`, `2510.00237`)
- **Core Premise:** When a small model (`1.7B–4B`) degrades under tight token budgets (`2k/4k`), practitioners can either optimize prompt allocation/schemas or apply parameter-efficient post-training (LoRA SFT).
- **Distinction from Our Work:** `PA-Tool` (`2510.07248`, `~80%` lower misalignment, up to `+17%` accuracy) and `ToolRL` (`2504.13958`, GRPO reward decomposition) operate at unconstrained context lengths, while `2510.00237` demonstrates that data-diverse SFT generalizes competitively with RL. None quantify the **Token Exchange Rate**—how many tokens of inference context budget verifier-filtered LoRA SFT recovers on held-out tasks and unseen tool catalogues—or measure how prompt manipulation impacts **vLLM PagedAttention prefix-cache hit rates** and real **TTFT**.

## 3. Formal Research Gap Statement (Copy-Ready for Interim & Final Reports)

> **Research Gap Formulation:**  
> While recent studies have independently examined tool-schema compression against retrieved RAG passages (*arXiv:2605.26165*), unified control-context compression (*arXiv:2608.01056*), and compaction-induced governance decay (*arXiv:2606.22528*), three critical questions remain unaddressed for small open-weight language agents ($\le 4\text{B}$ parameters):  
> 1. **The Schema-vs-History Exchange Rate in Multi-Turn Policy-Governed Environments:** In interactive tool-use domains where operational rules ($P$) must remain fixed, no prior benchmark study systematically maps the performance trade-off between API tool-schema capacity ($S$) and multi-turn interaction history ($H$) across strict **2k, 4k, and 8k** BPE token budgets.  
> 2. **Silent Policy Violations vs. End-State Task Success:** Existing agent leaderboards evaluate terminal database mutations while overlooking intermediate procedural breaches (such as unauthenticated account lookups or unconfirmed state changes) that escalate as context budgets tighten.  
> 3. **Post-Training Budget Recovery and Serving Cost Reality:** It remains unknown how much context budget parameter-efficient fine-tuning (LoRA SFT across varying dataset sizes and ranks) can recover on held-out tasks and unseen tool catalogues, or when token savings from history rewriting are negated in practice by reduced **vLLM PagedAttention prefix-cache reuse** and elevated **Time-to-First-Token (TTFT)**.
